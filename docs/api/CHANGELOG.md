# Changelog - API Documentation

## 1.21.2 — 2026-11-01

### Исправлено

- Резкое переключение в примере историй после отпускания drag: истории и группы плавно доводятся до конечной позиции. Настройка уменьшения движения сохраняет мгновенные переходы.

### Тесты

## 1.21.0 — 2026-11-01

### Исправлено

- Повторные вызовы `once` и обработчиков при изменении подписок во время `emit`.
- Обновление списка слайдов после изменений DOM и перерасчёт autoWidth, autoHeight и grid.

- Сохранение ручной остановки autoplay, выбор активной копии видео и обработка поздних media-событий.
- Загрузка вложенных lazy-изображений, очистка spinner, уникальность ID клонов и стрелки из iframe.

### Функционал freeSnap

#### Режимы перетаскивания:

```js
// Обычный режим - snap во время drag
drag: true

// Free mode - свободная прокрутка
drag: 'free'

// Free mode + Snap - свободная прокрутка с выравниванием
drag: 'free',
freeSnap: true
```

#### Примеры:

- Free mode без snap - momentum scroll без ограничений
- Free mode с snap - плавная прокрутка с автоматическим выравниванием
- Normal mode - классическое поведение слайдера
- Динамическое переключение режимов
- Free mode с peek и center

### Функционал padding

#### Поддерживаемые форматы:

```js
// Число (пиксели)
padding: 50

// CSS строка
padding: '2rem'
padding: '10%'

// Объект для горизонтального слайдера
padding: { left: 50, right: 100 }

// Объект для вертикального слайдера
padding: { top: 50, bottom: 100 }
```

#### Примеры:

- Базовый padding
- Padding в процентах
- Асимметричный padding
- Padding с несколькими слайдами
- Вертикальный слайдер с padding
- Адаптивный padding с breakpoints
- Смешанные единицы измерения
