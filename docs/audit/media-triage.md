# Разбор media, lazy и доступности

Версия и bundle hash указаны в SUMMARY. Основание — фактический DOM и публичные controls, затем чтение исходников для группировки причин. Исправления upstream сами по себе не доказывают баг Tvist.

| Case | Классификация | Основание и границы |
|---|---|---|
| MEDIA-002/005/034 | reproduced; TVIST-AUDIT-014 | Ручной stop теряется при hover/hold. Это одна группа, а не три дефекта. |
| MEDIA-020 | reproduced; LAZY-NESTED | loadAll оставляет data-src у всех семи изображений внутри ссылок. README LazyLoad обещает поиск всех изображений с data-src/srcset; local_register использует только children(slide). Нельзя считать успешно проверенными picture/srcset и динамическую регистрацию на основании этого кейса. |
| MEDIA-024 | reproduced; INSTANT-ACTIVE | Изображение целевого слайда становится eager, realIndex и transform соответствуют 5, но active-класс остаётся у 0. Это дефект DOM-состояния после instant scrollTo, а не native lazy. |
| MEDIA-026 | reproduced; CLONE-FORM-IDS | Девять input имеют только три уникальных id. Документ не удовлетворяет уникальности id; label/for в копиях неоднозначны. Перенос введённых значений между клонами этим тестом не проверялся. |
| MEDIA-030 | reproduced; LAZY-DESTROY | После destroy остаются шесть созданных spinner. local_destroy обнуляет local_entries до удаления spinner по этой очереди. Это доказанная неполная очистка DOM, не заявление о heap leak. |
| MEDIA-032 | contract-gap; PAGINATION-KEYBOARD | Сгенерированные span не дают входа с Tab. Raw-кейс теперь явно отличает этот пробел доступности от дефекта документированной keyboard-опции, которая не реализована. Следующие шаги активации заблокированы отсутствием входа. |
| NATIVE-002 | reproduced в Chromium/Firefox; TVIST-AUDIT-010 | Реальное видео играет в физически невидимой копии. WebKit codec preflight не прошёл до создания Tvist. |
| NATIVE-003 | reproduced в Chromium/Firefox; TVIST-AUDIT-011 | Реальный поздний ready возобновляет неактивный элемент после ухода. WebKit заблокирован кодеком. |
| SRC-M01 | contract-gap | Явный вызов сохранённых autoplay controls после destroy оживляет старый owner и меняет общий root нового экземпляра. Публичная политика вызовов уничтоженных controls не определена; это наблюдаемое опасное поведение, но в реестр подтверждённых нарушений API оно не включено. |
| SRC-M02/03 | pass в повторных браузерных проверках | Реальные image load/error после destroy не мутируют сохранённый DOM и не вызывают callbacks владельца. DOM намеренно удерживается fixture; GC этим кейсом не проверяется. |

MEDIA-008 первоначально был ошибкой fixture: CSS visibility у root явно переопределял родителя. Исправленный вариант прошёл; историческое падение остаётся только в диагностическом журнале. Axe в MEDIA-031 прошёл в выбранном состоянии; это не подтверждает полноту клавиатурной или screen-reader доступности.
